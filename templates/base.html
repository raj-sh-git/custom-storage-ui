Storage UI v2.2 Changelog
Latest
  • 3-Dot (⋮) Action Menus: Quick CRUD actions across Blobs, File Shares, Queues, and Tables (Edit, Rename, Move/Copy, Clone, Delete).
  • Cross-Container & Share Transfers: Seamlessly move or copy files and entities across containers, shares, and tables.
  • Table Entity Studio: In-browser JSON entity editor, duplication / cloning, and cross-table entity migration.
  • Single-Line Queue Preview: Clean single-line truncated message preview with non-shifting toggle to full payload.
  • Multi-Select Bulk Deletion: Select multiple blobs via checkboxes and delete in a single batch.
  • In-Browser Blob Editor: View, edit, and save text, JSON, and code files directly to Azure Storage.
  • Instant Search Filter: Real-time instant filtering across blob names and paths.
  • Configurable Pagination: Choose 10, 15, 20, 50, or 100 items per page with fast slicing.
  • Upload Progress & Timeout Protection: Live progress tracking with 502/504 gateway timeout handlers.
  • Queue Multi-Select & Routing: Select, bulk dequeue, edit messages in-place, and move/copy messages across queues.
  • Base64 & Plain Enqueue: Native Base64 encoding to prevent Azure Function poison queues, with smart auto-decoding.
  • Bulk Resource Studio: Batch-create containers, queues, tables, and shares via CSV/Excel.
